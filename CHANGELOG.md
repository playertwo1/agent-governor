# Changelog

## 1.0.0 — 2026-09-13

- First installable project-level release.
- Fail-closed policy engine and Antigravity `PreToolUse` integration.
- Persistent task state and circuit breaker in SQLite.
- Fingerprinted validation receipts and structured audit output.
- Generic, Python, Node, Android/Kotlin and n8n/Telegram starter profiles.
- Idempotent install, safe uninstall, diagnostics and CI tests.

The release provides local governance with Antigravity. Host isolation, remote branch protection and end-to-end host validation must be configured by the project owner.
